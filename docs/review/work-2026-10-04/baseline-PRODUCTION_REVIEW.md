# TETRA 0.2.0 — 최종 프로덕션 준비도 리뷰

검토일: 2026-10-04. 대상: 이 문서와 함께 묶인 `tetra-atlas` 소스 스냅샷. 원격 커밋을 기준으로 한 리뷰가 아닙니다. 원격 저장소 생성·업로드와 실제 배포는 완료하지 못했습니다.

## 1. 판정

**정식 프로덕션 승인 보류. 버그 수정·보안 보강이 적용된 실험용 공개 베타 후보입니다.**

일반적인 이동·확대·CPU 계산은 실행 검증을 통과했습니다. 하지만 실제 브라우저 WebGL2, iPhone/Safari, 공개 HTTPS 동작, 원격 CI가 확인되지 않았습니다. “어디까지나 실시간·고해상도로 탐험”이라는 제품 약속도 현재 충족하지 않습니다.

구현한 계산 범위, 실제 성능, 검증한 실행 환경이 제품 약속보다 좁습니다. 고정밀 계산의 가속·타일 해상도 개선은 별도 구현 과제입니다.

## 2. 변경 범위

첨부된 `tetra-atlas-github-ready.zip`을 기준으로 핵심 소스·정적 빌드·로컬 서버·배포 설정·테스트·README를 검토했습니다. 수정은 현재 작업본에서 수행했으며 다른 저장소, 계정, Vercel 프로젝트, 도메인, 라이선스를 변경하지 않았습니다. 새로운 서비스나 백엔드 의존성은 넣지 않았습니다.

## 4. 실제 실행한 검증

| 검증 | 결과 | 범위 |
| --- | --- | --- |
| `npm test` | 57 통과, 실패/건너뜀 0 | 기존 40 + 독립 참조 13 + 빌드/서버/보안 4 |
| `npm run build` | 통과 | 단일 HTML 76,203 bytes, 정확한 CSP 해시 포함 |
| 브라우저 회귀 | 29 통과 | Chromium 144.0.7559.96 + Playwright 1.57.0 |
| 소프트웨어 GLES | 8 통과 | 실제 production GLSL 컴파일 2, 링크 1, 픽셀 5 |
| 독립 고정밀 비교 | 12 입력 통과 | mpmath 300자리 참조, 240자리 구현의 첫 4번 반복 비교. 57개에 포함 |

원본 증거는 `docs/review/unit-tests.txt`, `browser-review.json`, `gpu-software.json`에 보관합니다. 현재 소스 및 증거 파일의 SHA-256은 `docs/review/SHA256SUMS.txt`에 있습니다. 최종 HTML·테스트 스크립트와 함께 검사 시점의 파일을 식별할 수 있습니다.

### 수치 검증 해석

허용 오차는 각 성분에 대해 `1e-221 × (1 + |참조값|)`입니다. 입력에는 양·음 실수, 일반 복소수, 음의 실수축 양옆, 매우 작은 입력, `1e-200` 차이의 좌표가 포함됩니다. Float64에서 사라지는 좌표 차이가 고정밀 유한 궤도에서는 보존되는지 따로 확인했습니다.

이 결과는 첫 4단계의 선택된 입력에 대한 비교입니다. 모든 1,024단계 궤도, 민감한 경계, 전체 프랙탈 모양, 보편적인 221자리 정확성을 보증하지 않습니다. 자체 고정소수점 라이브러리는 인증된 수치 엔진이 아니며 분류는 관측 후보입니다.

### 브라우저 검증 해석

CPU FP64와 BigInt 경로에서 실제 캔버스 계산을 완료했습니다. 휠 앵커·드래그·키보드·핀치·단일 터치·잘못된 입력·공유 좌표 복원·PNG·Worker 취소·CSP·모바일 포커스 순환을 검사했습니다. 모바일 화면 캡처는 패널의 CSS 이동이 끝난 뒤 수행하고 패널이 화면 안으로 들어오는지도 확인했습니다.

이 환경은 localhost 브라우저 탐색이 차단되어 빌드한 HTML을 `set_content`로 열었습니다. CSP meta는 그대로 적용했습니다. Node HTTP 통합 검사는 로컬 서버의 실제 응답을 별도로 검사했지만, 브라우저와 호스팅 헤더를 결합한 end-to-end 검증은 아닙니다. 의도적으로 차단시킨 두 CSP probe의 콘솔 메시지는 테스트 기대 결과입니다. 미처리 JavaScript 예외는 검출되지 않았습니다.

### GPU 검증 해석

렌더러는 `llvmpipe (LLVM 19.1.7, 256 bits)`, `OpenGL ES 3.2 Mesa 25.0.7-2`입니다. 앱의 실제 GLSL을 사용했고 5개 기준점의 RGB는 CPU 색상과 채널당 1 이하 오차 조건을 통과했습니다. 이는 브라우저 WebGL2, 정밀도 전환, GPU 드라이버, 컨텍스트 손실 복구를 실기기에서 검증한 것이 아닙니다.

## 5. 성능과 제품 목표

관측 샘플은 이 테스트 환경의 단발 측정입니다.

- 초기 CPU FP64 662×482, 반복 한도 256: 약 7–8초.
- 중심 `0.5+0i`, span `1e-200`, 반복 한도 64: 약 24초.
- 고정밀의 최종 계산은 최대 가로 72샘플. 캔버스 크기와 계산 해상도는 다름.

따라서 “확대할수록 새로운 좌표를 계산할 수 있음”과 “계속 실시간 고해상도로 탐험함”은 구분해야 합니다. 후자의 제품 목표는 미완료입니다. 특히 경계 주변에서 더 많은 반복이 필요하면 위의 단순 입력보다 훨씬 느릴 수 있습니다.

권장 다음 구현은 측정으로 병목을 확인한 뒤 고정밀 계산 비용과 타일 재사용·점진 해상도를 개선하는 것입니다. WASM 고정밀 라이브러리는 후보지만 선택·구현·속도 향상이 검증된 상태는 아닙니다. 단순히 확대 상한을 제거하거나 픽셀을 늘려서 완료된 것처럼 표시하지 마세요.

## 7. GitHub 실행 상태

인증 계정은 `MongLong0214`로 확인했습니다. 저장소 조회와 README 파일 생성 요청 모두 `404 Not Found`를 반환했습니다. 연결에는 파일·커밋·PR 쓰기 기능이 있으나 새 저장소 생성 기능은 없습니다. 조회만 가능한 연결이라고 설명하는 것은 현재 상태와 맞지 않습니다.

즉, 이번 작업의 결과는 **수정된 로컬 소스와 문서**이며 원격 커밋은 없습니다. 404만으로 저장소가 전혀 없다고 단정할 수는 없지만, 계정 내 검색에서도 접근 가능한 대상은 찾지 못했습니다. 대상 공개 저장소의 생성 또는 이 연결의 해당 저장소 접근 허용이 필요합니다. 개인 인증 토큰을 채팅에 제공할 필요는 없습니다.

`publish-github.sh`는 별도의 인증된 로컬 환경용 최초 생성 도우미입니다. 기존 저장소나 `.git` 폴더가 있으면 중단합니다. 이 환경에서는 인증·생성·푸시를 end-to-end 실행하지 않았습니다.

## 8. 보안·유지보수 범위와 근거

CSP는 빌드한 코드의 해시만 허용하며 `unsafe-inline`/`unsafe-eval`은 사용하지 않습니다. 보안 정책을 통과시키려고 테스트 환경에서 정책을 제거하지 않았습니다. 본문에 외부 링크·새 분석 코드를 추가할 때도 정책 변경과 재검증이 필요합니다. 프레임 차단은 meta가 아닌 HTTP 헤더로 설정합니다.

서버 경로 검증, 민감 파일 패턴 검사, 외부 실행·네트워크 의존성 검토, 입력 길이·좌표 범위 제한을 확인했습니다. GitHub/AWS/API 키와 개인 키 패턴의 범위 제한 검사에서 발견 사항은 0개였으며 `docs/review/security-scan.json`에 범위를 기록했습니다. 발견한 내용을 수정했지만 독립 침투 테스트나 모든 취약점 부재의 인증은 아닙니다. 압축된 스타일·짧게 작성된 일부 함수는 향후 변경 시 읽기 부담이 있으나 이번 출시를 위해 프레임워크로 재작성할 근거는 없습니다.
