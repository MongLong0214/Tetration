A NOTE FROM THE OBSERVATORY

보이는 풍경 뒤에 있는,
하나의 규칙.

복소평면의 점 z마다 w₀ = 1에서 시작해 wₙ₊₁ = exp(wₙ Log z)를 반복합니다. 이 앱은 로그의 주값을 사용하며, 음의 실수축에서 편각은 +π입니다. 원점은 정의하지 않습니다.

색은 유한한 반복 계산의 결과입니다. 임계값 |w| > 10¹⁰을 통과했다고 발산이 증명된 것은 아닙니다. 고정점·2주기는 근접한 값이 반복 관측된 후보이며, 미판정에는 더 긴 주기와 느린 수렴 등이 섞일 수 있습니다.

확대는 어디까지 가능할까?

일반 탐색에는 지원·기준점 검사를 통과한 WebGPU 또는 WebGL2 GPU, 더 깊은 확대에는 CPU 64-bit, 이후에는 BigInt 고정밀 계산으로 전환됩니다. 좌표는 256자리 고정소수점, 궤도 계산은 최대 240자리이며 가로 범위 10⁻²⁰⁰까지 이동할 수 있습니다. 수학적으로 무한한 확대나 결과의 정확성을 보증하지는 않습니다.

각 엔진의 허용 오차와 수치 처리 한계가 달라 경계 무늬가 바뀔 수 있습니다. 고정밀 계산도 오차 구간을 증명하는 방식이 아니며, 고정밀에서 처리 중인 타일은 점진적으로 채워집니다. 고정밀의 샘플 해상도는 최대 가로 72개로 제한되어 픽셀이 보일 수 있습니다.

탐험 방법

드래그·방향키로 이동, 휠·핀치·+/−로 확대합니다. 두 번 클릭하면 해당 위치를 확대하고, Home은 전체 지형으로 돌아갑니다. ‘위치 공유’는 좌표·반복 횟수·팔레트·계산 방식을 링크에 담습니다.

브라우저 안에서만 계산합니다. 로그인, 분석 추적기, 외부 API를 사용하지 않습니다. 고정밀 계산은 기기에 따라 느릴 수 있습니다.
